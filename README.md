# Team Task Manager

A full-stack Team Task Manager web application built using the MERN stack.  
This application allows users to create, manage, and track tasks with dashboard analytics.

## 🚀 Live Demo

### Frontend (Vercel)
https://team-task-manager-tau-pied.vercel.app

### Backend API (Railway)
https://team-task-manager-production-67f3.up.railway.app

---

# 📌 Features

- Create Tasks
- View All Tasks
- Dashboard Analytics
- Task Status Tracking
- Pending / Completed / Overdue Counters
- REST API Integration
- Responsive UI
- Full Stack Deployment
